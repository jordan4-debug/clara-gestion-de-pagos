# Guía breve para la exposición

1. Abrir el enlace de Cloudflare Pages. Mostrar que la dirección y el acceso son independientes de ChatGPT.
2. Iniciar sesión con correo y contraseña del propietario; mostrar el error al escribir una contraseña incorrecta.
3. Revisar los cuatro indicadores. Un monto por definir no se suma como si fuera cero conocido.
4. Abrir «Recurrentes» y preparar un mes. Repetir la acción y comprobar que no duplica obligaciones.
5. Abrir un pago que requiera autorización y autorizarlo como propietario.
6. Cerrar sesión y entrar como asistente. Registrar un abono con un comprobante ficticio y un número de operación único.
7. Revisar el estado parcial, completar el saldo y abrir el comprobante. Una segunda sesión debe mostrar los mismos cambios después de actualizar.
8. Revisar el historial. Aclarar que registrar un pago externo no ejecuta una transferencia.

La pasarela Izipay y los cobros reales siguen pendientes de la siguiente etapa. No afirmar que se ha cobrado dinero desde esta aplicación.
